# Правила роботи для AI-агента

## Моніторинг процесів та CI/CD
- При відстеженні віддалених або тривалих процесів (зокрема пайплайнів GitHub Actions):
  - **Завжди** використовувати нативні інструменти спостереження CLI у фоні: наприклад, `gh run watch <RUN_ID> --interval <N>`.
  - **Заборонено** використовувати штучні періодичні опитування через `sleep`, ручні цикли опитування або таймери (`schedule`) для перевірки статусу завдань.

## Привілейований доступ (Shizuku / rish)
- На пристрої встановлено та активровано Shizuku з доступом через CLI `rish` (контекст ADB shell, UID 2000).
- Для локальних операцій на пристрої (встановлення та оновлення APK через `pm install -r`, надання дозволів, перевірка чи запуск компонентів через `am`, зняття діагностики через `dumpsys` або `logcat`) використовувати виконання команд через `rish -c "<command>"`.
